# 割り勘・立て替え一発精算ルート計算機

複数メンバーがそれぞれバラバラに立て替えた費用を入力するだけで、最も送金回数が少なくなる精算ルートを自動計算するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/group-expense-splitter/）。
2. 画面の指示に従って操作します。
